# 授業資料 翻訳ツール

韓が担当する授業向けに試運用している、Canva資料とClassroomで配布されたPDFの翻訳ツールです。

**[導入ガイドを開く — 使い方とコードのコピーはこちら](https://xhan21.github.io/class-material-translator/)**

授業では、まず担当教員がこのツールで日本語の資料を英語に翻訳し、原文と訳文を教室前方の画面に表示する使い方を基本としています。

母国語で読みたい学生や、前方の英訳が見えにくい学生には、上の導入ガイドを案内してください。必要な学生が自分のパソコンにツールを導入し、読みたい言語や文字サイズで訳文を確認できます。

導入ガイドは学生向けに、Canva版・PDF版に共通する導入手順・使い方と、それぞれのコードをまとめています。教員ご自身がツールを導入する際も、同じ手順を利用できます。

## Tampermonkeyに貼り付けるコード

| 利用する資料 | 配布コード |
| --- | --- |
| Canvaの閲覧用資料 | [Canva版](canva-reading-panel.user.js) |
| Classroom・Google DriveのPDF | [PDF版](classroom-pdf-reading-panel.user.js) |

導入ガイドの「Canva版のコードをコピー」または「PDF版のコードをコピー」を押し、Tampermonkeyに貼り付けて保存してください。両方使う場合は、別々のスクリプトとして登録します。

## 翻訳元と翻訳先の選び方

Canva版・PDF版ともに、パネルの「翻訳元」で資料の言語、「翻訳先」で読みたい言語を選び、翻訳を開始します。翻訳元は手動で選択します。

- 英語の資料を日本語で読む：翻訳元「English」→ 翻訳先「日本語」
- 日本語の資料を英語で読む：翻訳元「日本語」→ 翻訳先「English」（初期設定）
- 原文を読む：翻訳元と翻訳先を同じ言語にする

既存の利用者は、Canva版 v2.9.0／PDF版 v0.4.2のコード全体に置き換えて保存し、資料のタブを再読み込みしてください。

## 作成方法と翻訳について

コードは、韓の指示のもと、助手として利用しているChatGPTが生成・修正しています。

資料の翻訳には、[Google Chromeの内蔵翻訳機能（Translator API）](https://developer.chrome.com/docs/ai/translator-api)を利用しています。

訳文は授業資料を理解するための補助であり、正確性を保証するものではありません。機械翻訳による誤訳や、文字の読み取り・読み順による抜けや誤りが生じる場合があります。授業で利用する際は、専門用語や課題の指示などの重要な内容を原文と照らし合わせ、必要に応じて補足してください。学生にも、訳文だけで判断せず、不明な点は担当教員に確認するよう案内してください。

公開ページと2本の配布コード、簡単な案内、公開に必要な設定ファイルを置いています。
