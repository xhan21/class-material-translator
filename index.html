授業資料 翻訳ツール
導入ガイド

韓が担当する授業向けに試運用している翻訳ツールの導入ガイドです。Canvaの閲覧用資料と、Google Classroomで配布されたPDFに対応しています。

日本語の資料を開いたまま、右側のパネルに訳文を表示します。ページを変えると訳文も更新されます。PDFを保存したり、別のサービスへアップロードしたりする操作は不要です。

01

パソコン版Chromeを用意する

このツールはパソコン版Google Chromeで使います。スマートフォンやタブレットのChromeには対応していません。

  1. 授業資料を読むパソコンで、Google Chromeを開きます。
  2. Chromeは138以降が必要です。古い場合は、Chromeのメニューから「ヘルプ」→「Google Chromeについて」を開き、更新します。Macでは上部メニューの「Chrome」→「Google Chromeについて」からも確認できます。
  3. 学校用と個人用のプロフィールを分けている場合は、CanvaやClassroomの授業資料を読むプロフィールで、続きの操作をしてください。

すでに最新版のChromeで授業資料を開いている場合は、そのまま次へ進みます。Chromeの翻訳機能について（公式）

02

Tampermonkeyを追加する

Tampermonkeyは、これから登録する翻訳ツールのコードをChromeで動かすための拡張機能です。追加済みの方は手順03へ進みます。

  1. 下のボタンから、ChromeウェブストアのTampermonkeyのページを開きます。
  2. 「Chromeに追加」を押します。
  3. 確認画面で「拡張機能を追加」を押します。
  4. 追加が終わったら、この導入ガイドに戻ります。
Tampermonkeyを追加する ↗

「Chromeから削除」と表示されている場合は、すでに追加されています。Chrome右上のパズル形の「拡張機能」からTampermonkeyを探せます。ピンのボタンを押すと、アイコンを常に表示できます。

03

スクリプトの実行を許可する

Tampermonkeyを追加しただけでは、翻訳ツールを動かせない場合があります。Chromeの設定で、スクリプトの実行を許可します。

  1. Chromeで新しいタブを開き、次の文字を画面上部のアドレスバーに入力してEnterキーを押します。検索欄ではなく、URLが表示される欄です。
  2. 拡張機能の一覧から「Tampermonkey」を探します。無効になっている場合は、有効にします。
  3. Tampermonkeyの「詳細」を開きます。
  4. 「ユーザースクリプトを許可」をオンにします。英語表示の場合は「Allow User Scripts」です。
  5. この導入ガイドに戻ります。

同じChromeプロフィールでCanva版などがすでに動いていれば、通常、この設定は済んでいます。項目が見つからない場合はChromeを更新し、Tampermonkey公式の設定手順も確認してください。

04

資料に合うコードを登録する

開いた先がCanvaの閲覧画面ならCanva版、PDFの閲覧画面ならPDF版を選びます。Classroomに貼られたCanvaのリンクを開く場合も、使うのはCanva版です。

必要な方だけ登録できます。両方使う場合は、1つずつ、別々のスクリプトとして登録してください。2つのコードを1つの編集欄に続けて貼り付ける必要はありません。

Canva資料用 v2.8.0

Canvaの閲覧用リンクで開くスライドに使います。Canvaの編集画面には対応していません。

登録する名前：Canva 閲覧用テキストパネル（試用版）

Canvaでの使い方

Canva版 v2.8.0

Canva版のコードを表示・手動でコピーする

コード欄をクリックし、⌘＋A → ⌘＋C（Mac）、またはCtrl＋A → Ctrl＋C（Windows）でコピーできます。

Classroomで配布されたPDF用 v0.3.0

Classroom内のPDFプレビューや、Google DriveのPDF閲覧画面で使います。PDFのダウンロードは不要です。

登録する名前：Classroom PDF 翻訳パネル（試用版）

PDFでの使い方

PDF版 v0.3.0

PDF版のコードを表示・手動でコピーする

コード欄をクリックし、⌘＋A → ⌘＋C（Mac）、またはCtrl＋A → Ctrl＋C（Windows）でコピーできます。

選んだツールを初めて登録する場合

  1. 使いたい方の「Canva版のコードをコピー」または「PDF版のコードをコピー」を押します。「コピーしました」と表示されることを確認します。
  2. Chrome右上のパズル形の「拡張機能」から「Tampermonkey」を開きます。アイコンを固定している場合は、直接クリックできます。
  3. 「新規スクリプトを追加」を選びます。英語表示の場合は「Create a new script」です。
  4. 開いたコードの編集欄をクリックし、⌘＋A（Mac）またはCtrl＋A（Windows）ですべて選択します。
  5. ⌘＋V（Mac）またはCtrl＋V（Windows）を押し、最初からあるコード全体をコピーしたコードに置き換えます。前後に元のコードを残さないでください。
  6. ⌘＋S（Mac）またはCtrl＋S（Windows）で保存します。
  7. Tampermonkeyの「ダッシュボード」を開き、コピーした版の名前が表示され、有効になっていることを確認します。名前は上の各コード欄に記載しています。

もう一方も使う場合は、そのコードをコピーし、もう一度「新規スクリプトを追加」から登録します。すでに動いている版は、追加のために更新する必要はありません。

登録済みのコードを更新する場合

  1. 更新する方のコードをコピーします。Canva版のコード／PDF版のコード
  2. Tampermonkeyの「ダッシュボード」を開き、コピーした版と同じ名前の登録済みスクリプトを選びます。新規作成は不要です。
  3. 編集欄をクリックし、⌘＋A → ⌘＋V（Mac）、またはCtrl＋A → Ctrl＋V（Windows）でコード全体を置き換えます。
  4. ⌘＋S（Mac）またはCtrl＋S（Windows）で保存します。

保存したら：すでに資料を開いているタブは、一度再読み込みしてから使ってください。新しいコードが反映されます。

05

資料の種類に合わせて翻訳を始める

Canva資料の場合 →ClassroomのPDFの場合 →

Canva資料の場合

  1. 授業で共有されたCanvaの閲覧用リンクをChromeで開きます。編集用リンクでは動作しません。
  2. 右側に表示される「Slide translator」パネルで、Englishなど読みたい言語を選びます。
  3. 「Start translation（翻訳を開始）」を押します。
  4. スライドを切り替えると、訳文も自動で更新されます。

Canvaの資料がClassroomでリンクとして配布されている場合も、開いた先がCanvaならこちらの手順です。

Classroomで配布されたPDFの場合

  1. 授業で配布されたPDFをClassroom内で開きます。Google DriveのPDF閲覧画面でも利用できます。
  2. 右側に表示される「PDF translator」パネルで、Englishなど読みたい言語を選びます。
  3. 「Start translation（翻訳を開始）」を押します。
  4. PDFのページを変えると、訳文も自動で更新されます。PDFを保存・アップロードする操作は不要です。

画像だけで構成されたPDFには対応していません。

どちらのツールも共通

日本語を選んだ場合は、「原文を表示」を押すと日本語のまま表示できます。ボタンの翻訳がオンの場合、ボタン名は選んだ言語に合わせて変わります。

初回はChromeが翻訳用の言語データを取得するため、少し時間がかかる場合があります。再読み込み後や言語変更後は、開始ボタンをもう一度押してください。翻訳にはChromeの内蔵機能を使用します。

うまく動かないとき

パネルが出ない
資料に合う版を登録したか確認します。Canva資料にはCanva版、PDFにはPDF版が必要です。資料を読むChromeのプロフィールで、該当のスクリプトと「ユーザースクリプトを許可」を有効にし、資料のタブを再読み込みしてください。Canvaの編集画面では動作しません。
Tampermonkeyのアイコンに赤い「1」が出る
実行されたスクリプトの数を示す表示です。赤い「1」自体はエラーではありません。公式説明
文字が表示されない・エラーが出る
資料の読み込みを待ち、開始ボタンを押してください。どちらの版も画像に含まれる文字は翻訳対象外です。Chromeや学校の管理設定によって、翻訳機能を利用できない場合もあります。
番号や文字色が元の資料と違う
番号は取得できる範囲で反映します。Canva版は文字の色情報を読み取ります。PDF版は行・段落ごとの代表色を画像から推定し、文中の一部分だけの色分けには未対応です。PDFの色を取得できない場合は濃いグレーで表示します。
Googleサイト上でコードのコピーができない
使いたい版の「コードを表示・手動でコピーする」を開きます。コード欄をクリックし、⌘＋A → ⌘＋C（Mac）、またはCtrl＋A → Ctrl＋C（Windows）でコピーしてください。

このツールは日本語の授業資料を読むための試用版です。資料の構成や利用環境によっては、文字・読み順・色を正しく反映できない場合があります。
